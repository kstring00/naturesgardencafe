# 5-minute user test

Run this with 3 people who have never seen the site. Phone only. Don't help. Write down what they say out loud.

## Setup
- Send them the deployed link by text, the way a customer would get it.
- Ask them to think out loud the whole time.

## The task (read it to them word for word)
> "You're hungry at home in League City. Decide if you can get food delivered from here, choose something, and start an order."

## What to watch for
| Moment | Pass looks like | Note the exact words if it fails |
|---|---|---|
| First 5 seconds | They say "Argentinian food / empanadas / delivery" without scrolling | |
| Delivery decision | They find "Delivery around Friendswood" and decide yes/no for League City | If they hesitate, we need the delivery area line from Marina |
| Choosing | They name an item and its price without asking | |
| Starting the order | They tap **Order delivery** (not Call, not scrolling for a form) | |
| Demo panel | They understand this is a demo and that a real checkout goes here | |

## Three questions after
1. "What would you have ordered, and why?"
2. "Was there anything you wanted to know before ordering that you couldn't find?"
3. "Would you use this instead of calling? Why or why not?"

## Scoring
- 3 of 3 tap Order delivery within 60 seconds: ship it.
- Anyone asks "do they deliver to me?": get the radius from Marina before the pitch.
- Anyone asks about hours: get hours before the pitch.
