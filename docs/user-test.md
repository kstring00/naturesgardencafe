# 5-minute user test (v2)

Run with 3 people who have never seen the site. Phone only. Don't help. Write down what they say out loud.

## Setup
- Text them the link, the way a customer would get it.
- Ask them to think out loud the whole time.

## The task (read it word for word)
> "You're at home in League City and hungry. Figure out what this place is, whether they'd deliver to you, what a milanesa is, and start an order."

## What to watch for
| Moment | Pass looks like | If it fails, note their exact words |
|---|---|---|
| First 5 seconds | They say "Argentinian food / empanadas / delivery" without scrolling | |
| "What is this place?" | They mention it's a café inside a health store, not a vitamin shop | |
| Delivery decision | They find "typical area" with League City and decide yes | If they hesitate: we need the confirmed area from Marina |
| "What's a milanesa?" | They read the one-line description and can say it back | |
| Starting the order | They tap **Order delivery** (not scrolling for a form) | |
| Order panel | They understand to call, and don't feel tricked | |

## Three questions after
1. "What would you have ordered, and why?"
2. "Was there anything you wanted to know before ordering that you couldn't find?"
3. "Would you use this instead of calling? Why or why not?"

## Scoring
- 3 of 3 tap Order delivery within 60 seconds: ship it.
- Anyone asks "how long?" or "is there a fee?": get those two answers from Marina before launch.
- Anyone asks about hours: get hours before the pitch.
